# Zephyr RTOS Threading Project

A comprehensive demonstration of Zephyr RTOS threading concepts and inter-thread operations.

## Overview

This project demonstrates all major RTOS concepts in Zephyr including:

1. **Thread Management**
2. **Synchronization Primitives** (Mutexes, Semaphores)
3. **Inter-thread Communication** (Message Queues)
4. **Thread Priorities and Preemption**
5. **Work Queues** (Deferred Processing)
6. **Timers** (Periodic and One-shot)
7. **Shared Resource Protection**
